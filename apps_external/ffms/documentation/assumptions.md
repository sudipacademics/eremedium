# Assumptions

- West Bengal is the initial territory seed; geographic entities have a hierarchy to support Pan-India expansion.
- Razorpay is the initial payment adapter and Cashfree remains an adapter option.
- Production Aadhaar eSign, KYC, Maps and messaging require selected compliant providers and their credentials; no synthetic authentication or credential values are included.
- Local host PHP is 8.0 and cannot run Laravel 12. Docker supplies PHP 8.3 when Docker Desktop is available.
